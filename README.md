# HTML → MP4 変換アプリ（サーバー方式）

モーショングラフィックス HTML をアップロードし、MP4（H.264 / 30fps）でダウンロードします。
Chromium（Playwright）で HTML を実際に再生 → 画面フレームを記録 → FFmpeg で MP4 化します。

## 使い方
1. ブラウザでアプリを開く
2. HTML をドラッグ&ドロップ（または選択）※プレビューで確認できます
3. 出力サイズを選択（9:16 / 1:1 / 16:9）
4. 動画の長さ（秒）を指定。`0` は自動（動きが 2 秒止まったら終了）
5. 「変換開始」→ 進捗表示 → 完成後に自動ダウンロード
   ファイル名例: `youtube-gemini-motion-20260930-9x16.mp4`

ループし続けるアニメーションは自動検出で止まらないため、秒数を指定してください。

## 起動
```bash
npm install
npx playwright-core install chromium   # 初回のみ（または CHROMIUM_PATH を指定）
npm start                              # http://localhost:3000
# Docker: docker build -t html2mp4 . && docker run -p 3000:3000 --memory=2g --cpus=2 html2mp4
```

## 課金暴走（クローラー大量アクセス）対策
| 対策 | 内容 |
|---|---|
| クローラー遮断 | `robots.txt` で全拒否、`noindex/noai` ヘッダ、主要な AI・スクレイパー UA は 403 |
| アクセス制限 | IP ごと 120 回/分、変換は IP ごと 10 回/時、サービス全体 200 回/日 |
| 同時実行 | 変換は同時 1 件、待ち行列は最大 3 件（超過は 503） |
| 上限 | アップロード 10MB、動画 60 秒、1 件 180 秒でタイムアウト、フレーム数上限 |
| 自動削除 | アップロード HTML は処理直後、MP4 はダウンロード後／10 分後に削除 |
| パスワード | `APP_PASSWORD` を設定すると全体に Basic 認証（**公開するなら強く推奨**） |
| 外部通信遮断 | アップロード HTML からの外部アクセスはフォント/CDN の許可リスト以外を遮断 |

上限値は環境変数で変更できます（`MAX_DURATION_SEC` `MAX_UPLOAD_MB` `MAX_JOBS_PER_IP_PER_HOUR` `MAX_JOBS_PER_DAY` `MAX_CONCURRENT_JOBS` `MAX_QUEUE` `FILE_TTL_MIN` など。`lib/config.js` 参照）。

### 運用側でも必ず行うこと（アプリ側だけでは防げません）
- **従量課金でない、または上限のあるホスティング**を選ぶ（固定料金プラン、予算アラート＋自動停止）。
- クラウドの**予算アラート**を設定（例: 月 5,000 円で通知・停止）。
- CDN/WAF（Cloudflare など）のボット対策を有効化し、リバースプロキシ配下では `TRUST_PROXY=1` を設定。
- 使わないときはサービスを停止、または `APP_PASSWORD` で限定公開。

## 注意
- 処理中はブラウザを閉じないでください。
- アップロード HTML は JavaScript を実行します。信頼できるファイルのみ使い、公開運用では必ずパスワードとコンテナ制限を併用してください。
- 音声・字幕・バッチ処理は対象外です。
